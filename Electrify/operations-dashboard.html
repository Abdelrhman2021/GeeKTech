Operations Dashboard

A look inside the console operators use to run a private mobility network: fleet summary, live driver tracking, ride configuration, promotions and payments.

Screens are shown with sensitive details obscured. Values and vehicle positions are illustrative.

Your whole operation at a glance

A single overview of cars, drivers, rides and transactions, broken down by ride category and payment method.

  • Cars, drivers, rides and transactions in one view
  • Fleet mix across economy, premium and pooling
  • Payment mix across card, cash and wallet

Live driver tracking

See where drivers are on an interactive map, switch between map and satellite views, and refresh on demand.

  • Driver locations on a live map
  • Map and satellite views
  • One-click map refresh

Configurable ride types

Define the ride options your riders can choose from, and control how each one behaves.

  • Economy, premium and pooling behaviours
  • Active hours for each ride type
  • Access controlled by user type
  • Filter the list by any column

Promo groups

Organise promotions into groups and manage them in a few clicks.

  • Create, edit and delete promo groups
  • Filter and page through the list

Payments and transactions

A filterable record of payments, with transaction type, payment method and user type at a glance.

  • Transaction type, payment method and user type
  • Column filters to narrow the list
